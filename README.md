# 45 Feet

A condensed, illustrated website of Jan Breemer’s *Soviet Submarines: Design, Development and Tactics* (Jane’s, 1989). About a 15–20 minute read.

## Read it

```bash
cd site
python3 -m http.server 8765
```

Open [http://localhost:8765](http://localhost:8765).

Or open `site/index.html` directly (Google fonts need the network).
